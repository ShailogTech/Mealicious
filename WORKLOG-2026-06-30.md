## 2. Fixing the 500 crash — the Carousel import mismatch
- `src/components/mealicious/HomePage.tsx` (lines 29–31) imported three new pieces:
  - `NeuHero` (the new hero)
  - `CarouselDemo` (`@/components/ui/carousel-demo`)
  - `Carousel` via **default import** from `@/components/ui/carousel`
- The dev log error was: **"Export default doesn't exist in target module"** at line 31.
- The reason: both `HomePage.tsx` and `carousel-demo.tsx` use `<Carousel slides={[{title, subtitle, price, button, src}]} />` — that's the **Aceternity UI** carousel API (default export). But the file at `@/components/ui/carousel.tsx` was the **shadcn** carousel — a *named* export (`Carousel, CarouselContent, CarouselItem, CarouselPrevious, CarouselNext`) that uses child components, not a `slides` prop.
- A grep showed the shadcn carousel was **dead code** — only those two files referenced that path, and both wanted the Aceternity one.
- **Fix:** replaced `src/components/ui/carousel.tsx` with an **Aceternity-style 3D-tilt Carousel** as a **default export**, extended to render `subtitle` and `price` fields (the original Aceternity component only has title/button/src). Key internals:
  - `Slide` subcomponent with a mouse-move 3D tilt using `requestAnimationFrame` writing `--x`/`--y` CSS variables, `perspective: 1200px`, `scale`/`rotateX` transforms, and an image overlay.
  - `CarouselControl` prev/next buttons using **lucide-react `ArrowRight`** (deliberately *not* `@tabler/icons-react`, to avoid adding a dependency).
  - `Carousel` default export managing `current` state and the slide track transform.
- Verified the homepage returned **200** and a fresh puppeteer load reported **zero page errors**.

- Diagnosis: the rewritten `carousel.tsx` has **no `@tabler` import** (it uses lucide). The errors were prefixed `[browser]`, meaning they came from a **still-open stale tab** holding the old compiled chunk that referenced `@tabler`.

- Guidance: hard-reload (`Ctrl+Shift+R`), or use Incognito, or DevTools → "Empty Cache and Hard Reload".
- Side note: `puppeteer-core` had been removed by an earlier clean `npm install`, so it was reinstalled with `npm install --no-save puppeteer-core`.

## 7. Filling the empty left space in the carousel
- The empty left gap happened because the carousel started on the **first slide** — there was no previous card to peek on the left, while the next card peeked on the right (asymmetric).
- **Fix (looping):** in the `Carousel` default export, the slides are now **tripled** (`[...slides, ...slides, ...slides]`), centered on the middle copy (`effective = slides.length + current`), driving the track with `translateX(-${effective * (100 / total)}%)`. Prev/Next use modulo wrap-around; click-to-select maps the display index back to the real index.
- Result: the active card is **always flanked by a previous card on the left and a next card on the right** — no empty side, on any slide. Applies to both sections.
- Caveat: wrapping from the **last slide back to the first** animates as a quick "rewind" through the slides; can be made instant/seamless on request.
